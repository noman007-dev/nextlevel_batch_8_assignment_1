# TypeScript Assignment

## Overview

This assignment shows  fundamental and advanced TypeScript concepts in practical code task . Type safety, functions, generics, interfaces, object-oriented programming and asynchronous programming are being used in this assignment.

## Topics Covered

- Functions: Optional parameters, union types, and type narrowing.
- Tuples: Using readonly tuples to represent coordinates.
- Generics: Creating reusable functions for array concatenation and property extraction.
- Interfaces: Defining structured objects and filtering popular courses.
- OOP: Classes, inheritance, and access modifiers (`public`, `private`, `protected`, and `readonly`).
- Async/Await: Implementing asynchronous age validation using Promises.
